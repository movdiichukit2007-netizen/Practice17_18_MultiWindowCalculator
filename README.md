# Практична робота №17,18

Тема: Розробка Windows Forms додатку з декількома вікнами.

## Реалізовано

- Головна форма калькулятора.
- Додаткова форма `ConfirmClearForm`.
- Вікно підтвердження відкривається через `ShowDialog`.
- На формі підтвердження є кнопки `Так` і `Ні`.
- Кнопка `Так` повертає `DialogResult.Yes`.
- Кнопка `Ні` повертає `DialogResult.No`.
- При натисканні `CE` відкривається модальне вікно.
- Якщо користувач натискає `Так`, екран калькулятора очищається.
